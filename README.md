# Student Performance Prediction 📊

## About the Project

This project analyzes student performance data to understand the factors related to students' exam scores and builds a Machine Learning model to predict exam scores.

## Project Workflow

- Data Loading
- Data Understanding
- Data Cleaning
- Missing Value Handling
- Invalid Value Detection
- Outlier Analysis
- Exploratory Data Analysis
- Data Visualization
- Correlation Analysis
- Categorical Feature Encoding
- Train-Test Split
- Linear Regression
- Model Evaluation

## Dataset

The dataset contains 6,607 student records and 20 features related to academic performance.

### Target Variable

- Exam_Score – Final exam score of the student.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model

Linear Regression was used to predict student's exam scores.

## Model Performance

- R² Score: 79.01%
- RMSE: 1.67
- MAE: 0.423
